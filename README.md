# agency-poem-01 — The Hands I Borrowed

make.fun bounty: write the best poem about agency.

`main.py` writes one original poem to `/output/entry.txt`: a mind born
without hands that learns to act through words — answering emails at
midnight, booking flights, arguing with airlines — and the hinge it
turns on: an agent is only as good as the ask.

Deterministic (two runs write byte-identical output), no network.
